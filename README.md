# Riverside Community Health Center — Air Quality Dataset

## Data Release Status

**✅ Released (v1.0)**

This repository contains the curated hourly air-quality measurements collected at the Riverside Community Health Center monitoring station, together with the quality-control pipeline and the data dictionary. The dataset is distributed under the CC BY 4.0 licence.

## Site Information

- **Site**: Riverside Community Health Center
- **Site type**: clinic
- **Address**: 12605 Riverside Dr, Eastvale, CA 91752
- **Monitoring since**: 2025-02-08

## Contents

- `data/` — curated hourly measurements
- `notebooks/` — quality control and analysis notebooks
- `src/` — loading and QC utilities
- `results/` — summary tables and figures
- `docs/` — data dictionary and calibration notes
